给 owner 画「这轮改完能看到的结果」时，样张里每一句都得是代码按固定规则能产出的。我手工翻提交、对数字推出来的原因（「周榜上次是空的」「多半来自某提交」「前端可以先画头几名」），只能当我这边的分析单独说，不能写进样张，否则 owner 会按一个产品做不到的效果拍板。

**Why:** 10-29 perf-lab 改判据时，我给的卡片样张里写了「原因：不是代码改动，周榜上次是空的」，owner 指出「这个其实是 ai 得出的，并不会在面板或者细节里展示」。后来改成只原样列程序能算的「这期间变化最大的」几项数字，不贴原因标签。同一轮里我还提过「内容变了的页就不比」，被 owner 顶回：「相当于没有性能测试的意义了」，变慢了就得报，原因留给看的人。

**How to apply:** 出样张前逐句问一遍「这句是哪个脚本、哪个字段产出的」，答不上来就挪出样张。引用实测数字换算成百分比前，先核清楚原始数据的基数和条件（同日我把 mac 上 867 ms / 22.8% 的波动当成集群 20 秒基数的「约 4%」报给 owner，后来才更正）。相关：[[not-ground-truth]]、[[perf-lab-report-technical-altitude]]。
