2026-08-04 工作模式体检抓出 4 条「活干完了、账没关」（T164 修完没回勾、creator_id 洗完记忆还写「等放行」、T36 拍了不做记成「没动」、多语言全落自查写「未落地」）——台账**单向高估欠债**，让用户自我核账偏悲观。

**Why:** 回勾没有「下一个 commit」的推进感，一被打断就沉底；没人负责关账，账就停在写完代码那一刻。

**How to apply:**
- 我报告「已合 main / 已上线 / 已修完」的同一轮，主动回勾**该项目自己的台账**（BACKLOG checkbox、memory 假待办）；改不动的（工作仓不明说不提交）明确提醒用户回勾
- 反向也算：拍板「不做」的记成已关闭，别继续挂着当欠账
- **绝不另建跨项目集中账本/清单**。2026-08-06 我据体检建了全局「人工闸清单」+ 每周提醒 hook，被顶回整套拆除（原话「loop_project 是以项目维度走的」）：用户的目录组织就是项目维度，每个项目的 BACKLOG/DONE 是自己的单一真相，全局层只放偏好/工作法——与 [[feedback-project-intel-stays-in-project-docs]] 同一精神。「只有本人能做的活」也记在**它所属项目**的台账里，不聚合
