修改文案、帖子、文章等长文时，每一轮修改后都返回完整的最新全文（v2/v3/v4 标号），不要只返回改动段、diff 段或省略号占位。即使只改了一两处也要整篇完整贴出。

**Why:** 用户在手机界面（尤其小红书内容创作场景）很难把零散改动段和前文拼起来还原全貌，看不到改后的整体节奏和效果，影响判断。

**How to apply:** 写小红书帖子、文章、邮件、文档、长 prompt 等任何长文修改场景，每轮都给完整最新版本，标 v2/v3/v4。改动小也照贴全文，不用 "..." 或 "其他段落不变" 这种省略写法。代码 diff 不在此规则范围内（diff 工具天然 diff 格式）。
