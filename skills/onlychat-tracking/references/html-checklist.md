# 核对 HTML 生成指南

> 模板 = 同目录 `checklist-template.html`（世界卡那份的样式 + 全部 JS 逻辑，直接复刻，别重写）。生成 = 复制模板 → 换数据。

## 模板自带的功能（别动 CSS/JS，只换数据）

- **1:1 PM 行序镜像**：三段表（按 PM 的「流程」分），行序照 PM 原顺序，**不要按自己的 A/B/C 重排**
- **第一列复选框** + `localStorage` 持久化 + 右上「已核对 N/总」进度（JS 自动注入，按 `.ref` 当 key）
- **白天/夜间切换**（右上按钮，持久化）+ 加大字号
- **代码事件名 📋 复制按钮**（右对齐，点了复制 cus.* 名）
- **可达性徽章**：浅(灰)/弹窗(灰)/**深(红)**/系统(灰)，文字非 emoji（JS 按 `TIPS` 渲染）
- **hover 可达路径气泡**：移到事件名上 → 弹 tier + 位置 + 路径 + `📄 组件:行`（JS 按 `TIPS` 渲染）

## 生成步骤

1. **复制模板**到目标位置（如 `~/Desktop/<功能>埋点核对.html`）。
2. **换三段表的行**（`<tr>`）：每行按 PM 清单一条，列结构：
   ```
   <tr><td class="ref">A1</td><td>模块</td><td>事件(PM描述)</td>
       <td><code>cus.xxx</code></td><td class="p">参数</td>
       <td><span class="badge b-ok">✅</span></td><td class="note">备注</td></tr>
   ```
   - `ref` = 你给的编号（A1/B2/C3…，与气泡 TIPS 对应）
   - 状态徽章四档：`b-ok`✅符合 / `b-fix`🔧待改代码 / `b-pm`⚠️待PM拍值 / `b-no`🚫不做
   - 备注列短；不做的行事件名/参数填 `<td class="p">—</td>`，无 `<code>`（不会有复制按钮/气泡）
3. **换 `TIPS` 对象**（`<script>` 里）：用 `tracking_tool.py tips <prefix>` 出骨架（file:line+fn 已填），你补每条的 tier/位置/路径：
   ```js
   'cus.xxx':['浅|弹|深|系', '位置一句话', '路径(怎么触发，浅可空)', '组件:行号'],
   ```
   - tier 决定徽章颜色 + 气泡分级：**浅**给位置即可 / **弹窗**给"怎么触发这个弹窗" / **深**给多步+前置(⚠️) / **系统**写"系统/无 UI"+条件
4. **顶部 meta + stats** 改成本次的分支/日期/计数（✅/🔧/⚠️/🚫 各几条）。
5. 浏览器打开自查：徽章出来、hover 有气泡、勾选持久化、白天/夜间切。

## 气泡数据来源（真实，别编）

`TIPS` 的「组件:行」用 `tracking_tool.py tips <prefix>` 抓真实 call-site；位置/路径按组件名 + 流程推（如 `*Dialog.tsx`→弹窗、`EditorHeader`→编辑器顶栏）。系统事件（无 UI）tier 填 `系`，气泡写触发条件。

## 与 i18n skill 的 HTML 区别

i18n 那份是「新建/复用 key 清单」；本 skill 这份是「PM 埋点清单 1:1 核对 + 验证勾选」。两者都是给人逐条对照用的离线 HTML，但列和交互不同，别套用。
