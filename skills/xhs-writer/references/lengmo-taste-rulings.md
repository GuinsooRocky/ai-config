# 号主品味判例集（lengmo 真实裁决，2026-07-06 Fable 编纂）

> 这份文件跟 SKILL.md 的「绝对禁区」不是一回事：禁区管**词汇层**（哪些词不许出现），判例管**句子结构层**（哪类写法会被号主毙掉）。每条判例都来自号主当场抓过的真实案例，带日期可溯源。
> **权重规则：规则可以争辩，判例不可以。** 改稿时拿不准某句行不行，先在这里找同类判例——有同类，照判；没有，再回一般规则。
> 所有判例底层是同一把尺（号主原话）：**品味**。该专业时精准立得住，该浅白时小白接得住，不土、不端、不喊情绪、不报菜名。

## 判例一：口语化 ≠ 注水（2026-06-23）

源文章原句「一份磁盘记忆」，干净准确。我改成「加一个专门记东西的地方」——奶声奶气绕一圈。同批被毙的还有：原词「五大件」被我硬凹成「五个大件」。

号主判词：「那些文章每一句都没有 AI 味，你为什么不学一学，自己非得口语化处理，结果整得这么 AI 味。」

**裁定**：源文的 register 干净密实，就贴着走。准确术语立得住就别绕。动手前先问这一句是**去味还是注水**——怕读者不懂而加的填充，本身就是 AI 味。

## 判例二：例子前不搭台子（2026-06-24，号主当场示范）

我写的（毙）：

> 先给这个 loop 派个真活，我们天天干的那种。

全是预告和表态，「真活」「那种」零信息。号主改的（判决）：

> 举一个实际 loop 案例：监控禅道 bug 单 → 流转到 claude -p session → 找 worktree 空闲检测 → 改 → 验 → 提交 → 写 pr message → 通知。

引子压成一句平的，反而塞进**更密的真细节**——因为这些细节替你证明「任务真复杂、但 loop 搞得定」。

**裁定**：① 引子要平、功能化，别预告别表态，张嘴就上具体的；② 密度给在信息上、不给在口水上，承重细节越多越好；③ 别预报结构（「拆开看五个功能」这种提前抖答案的句子删掉，留悬念）。**去注水 ≠ 变短，是拿承重细节换掉空话。**

## 判例三：一个意思只说一遍（2026-06-24，号主单列强调）

被抓的四种啰嗦：
- 同义双写：「做了收不回来」+「不可逆」——同一个意思两遍
- 表态填充句：「这不是吓唬人」「说白了」——不承载信息，只表演语气
- 对仗金句：「替你干活也在替你犯错」——工整即可疑
- 例子铺太满：一个真实案例讲三行

**裁定**：一个意思一遍。承重细节留，空话和重复砍。**对仗金句出现 = 是我加的，删。**

## 判例四：号主给了原话，原样用（2026-06-22 起反复踩，最重的一条）

号主给了自己的口播/大白话时，我反复把它「优化」坏：顺成工整排比、塞「为什么是这三个——」这类连接词、把他的口语提炼成「三支柱」黑话、造「差的不是模型，是你给它搭的环境」这种口号。

**裁定**：原样用，只清语音转文字的标点毛刺，**语气、选词、甚至啰嗦都保留他的**。AI 味指纹四件套，出现即我加的、直接删：报菜名三件套、破折号接金句、「不是 X 而是 Y」对仗、正确废话。

## 判例五：黑话与「墙」（2026-07-04）

禁用词之外的深层病：把用户已知已接受的**前置条件**（要付费登录、Mac 别休眠、每个渠道建 bot）渲染成「墙」「天花板」「blocker」。号主视角这些只是正常的上手事实。「北极星」这个词号主明说「讨厌到不想在电脑里出现」。

**裁定**：大白话讲产品。前置条件的正确动作是**写进说明书、在向导里替用户挡掉**，不是当障碍反复掂量。Persona / RCE / footgun / fail-closed / 北极星 / 墙 / 天花板，一律换人话。

## 判例六：精准 × 共情，缺一不可（分享/口播线的正例）

验证过的好句式（claude-code-workflow-talk）：
- 讲「模型失忆」→「你离开一会儿回来，它忘了十分钟前自己写的代码」
- 讲「模型会完美地写错」→「泡杯咖啡回来，它把十几个文件全改了、全跑通、但全错」
- 讲「缓存边界」→「账单莫名跳水，可一行报错都没有」

**裁定**：每个技术点焊一个听众**亲历过**的现场——不是打比方让他想象，是点破他早已经历、只是没说清的那个时刻。写完逐句自检：只精准没共情 = 念文档；只共情没精准 = 听段子。缺哪头补哪头。
