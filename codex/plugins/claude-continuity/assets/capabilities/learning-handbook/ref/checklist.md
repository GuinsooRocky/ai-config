# 交付前自检

逐条过，不过的当场改。报告里写「自检 N/N」。

## 定义先行

- [ ] 第 0 章第一屏是主题词本身的字面定义（如 DAG = 图 / 有向 / 无环），配一个读者天天在用的例子
- [ ] 每章第一屏是「定义」块：大白话、一屏内、本章要用的词全给名字
- [ ] 全文没有一段在讲「怎么学这本书」；使用说明 ≤3 行且折叠

## 倒推

- [ ] 第 0 章有目标—检验表，4–8 行，每行「学完能 + 动词」（折叠或放章末，不占第一屏）
- [ ] 每条检验是换场景任务，不是「说出 / 解释 X」
- [ ] 每条检验能指到正文里具体的练习编号
- [ ] 末章逐条回收这张表

## 贯穿例

- [ ] 只有一个，有名字、有编号、有数字
- [ ] 第 0 章介绍它（表 + 图）
- [ ] 每章至少一次在它身上算 / 写 / 改 / 破
- [ ] 末章把它做成玩具跑起来
- [ ] 中途没换例；反例都写了「换一张图」并回到贯穿例

## 章

- [ ] 目录（含附录）≤ 8 条；不到 8000 字的知识点已并进邻章
- [ ] 一章 h3 ≤ 3（练习 + 并章分界），其余小标题是段首加粗；全书每千字 ≤ 1 个 h3
- [ ] 章名是「能做的事」，不是知识来源
- [ ] 后一章用到前一章的产物
- [ ] 定义 + 八块齐全、顺序固定、块名固定
- [ ] 「先做」在「定义」之后、「概念」展开之前，拿定义就能起步
- [ ] 「概念」第一句接读者刚做的结果；术语在机制之后才出现
- [ ] 「演示」带全部中间步骤（前几章）；后几章脚手架递减
- [ ] 「练习」≥2 个变体，含一个「改参数」和一个「弄坏」，每个是问题 + 折叠对照，没有输入框 / 勾选框
- [ ] 「这里会错」是本章的误读，不是攒起来的附录
- [ ] 「回头题」用的是 N−2 章之前的材料
- [ ] 「记进规格」是列表，逐章累积
- [ ] 来源 / 工具名降级在「这招从哪借的」小框里

## 检验

- [ ] 自测答案不能在上文 3 段内逐字找到（抽 5 题查）
- [ ] 每 ~1000 字有一处需要动手的停顿
- [ ] 答案全部折叠
- [ ] 附录有冷测：≥10 题、全新场景、无提示、标「隔三天再做」

## 终局

- [ ] 玩具实现 100–200 行、用学习者主力语言、能跑
- [ ] ≥5 个破坏实验，每个三列：怎么破 / 期望看到 / 对应哪章
- [ ] 「我的规格 vs 参考规格」差异表，参考规格在这之后才出现

## HTML

- [ ] 每章有底色 / 边框的容器 ≤ 2（练习、代码）；定义 / 情境 / 概念 / 演示是正文段落，块名不出现在页面上
- [ ] 没有每章开头的「学完你能」框（目标表只在第 0 章，折叠）
- [ ] 双击能开，无 CDN、无远程字体
- [ ] 目录每项指向真实 section id
- [ ] 全书带边框的表 ≤ 2；没有 textarea / checkbox / 进度条 / localStorage
- [ ] 图标全是内联 SVG，无 emoji
- [ ] 手机宽度不横向滚动（表格在 overflow-x 容器里）

## 文字

- [ ] 原料里标了来源的事实和数字一字未改，来源清单在附录
- [ ] 没有「首先 / 其次 / 综上 / 值得注意的是 / 本质上」
- [ ] 一个意思只说一遍
- [ ] 覆盖用户文件前已 `cp` 到 `~/.Trash/`，报告里说明
