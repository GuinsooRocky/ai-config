# 建造者自查 prompt

只在「项目」档用。设计写完、交给用户之前，用 Agent 工具派一个 `general-purpose` 子 agent（新上下文，不要 fork），把下面方括号里的领域和设计路径填好。设计还只在对话里时，先写到 scratchpad 再给路径。

```
你是一位能干的 [领域，例如「前端工程师」「活动策划」]。你拿到一份设计，要据此做出实施计划，而且没法联系写这份设计的人。

读 [设计文件路径]。

只报告你在能做好计划之前还必须弄清的问题：那些你只能靠猜、而猜错会有影响的地方。每条给出问题本身，以及为什么它的答案会改变计划。按重要性排序。

跳过设计里明确留给建造者自己定的部分，跳过你自己就能合理决定的事，跳过措辞上的挑刺。

如果没有重要问题了，就回答「没有重要问题」。
```

拿回结果后按 SKILL.md「建造者自查」的三堆分法处理：已经答过的、小事、只有用户能答的。
