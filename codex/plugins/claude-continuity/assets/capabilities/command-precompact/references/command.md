description: 压缩前先判断需不需要压，再按档位(快/中/细)面板交互选保留内容，产出可粘贴的 /compact 指令
---

扫一遍当前对话，按这几桶归好(先别输出明细):
0 本轮总目标(我们到底在干嘛)
1 还在跑的线(没做完的任务或讨论)
2 已拍板的决定(结论 / 选型 / 约定)
3 碰过的文件和路径
4 没收尾的 todo

第一步 · 判断现在需不需要压:
- 依据:对话长度 + “可丢内容”(已完成/废弃的线、调试输出、跑偏的探索)占比。
- 这只是启发式判断，精确余量以我这边的 context 仪表为准——给结论时提醒我自己瞄一眼仪表。
- 判断“需要压” → 直接进档位面板。
- 判断“还不用压” → 用 AskUserQuestion 弹单选面板 [先不压(推荐) / 我就是要压]:选“先不压”就停下并说明理由;选“我就是要压”就进档位面板。这个口子必须留，我说压就得能压。

全程用面板交互，别让我打字。

档位面板(AskUserQuestion 单选):
- 快:你直接按推荐输出一行 /compact
- 中:先列四桶明细 + 留 / 丢推荐，再弹单选面板 [就这样出指令 / 改几条];选“改几条”才进勾选面板
- 细:直接进勾选面板

勾选面板(中档选了“改几条”或细档时):AskUserQuestion 多选，每条按推荐为默认列出，我勾中的 = 翻转该条(留↔丢)，只勾想改的那几条，不从头勾。确认后出指令。

最终只输出可粘贴的 /compact 那一行(中 / 细档可在前面带明细)。

生成 /compact 指令时带上格式要求:压缩后的摘要开头先钉两行——【目标】和【下一步】(含还在跑的线 + 没收尾 todo);其余(已拍决定、文件路径)压成正文即可，不必保留桶的标签。
